📘 HƯỚNG DẪN SỬ DỤNG WEBSITE

  1. Mở trang chủ bằng cách nhấp đúp vào file index.html.
  2. Chọn bài tập 27, 28, 28a hoặc 28b để mở bài tập tương ứng trong tab mới.
  3. Với các bài trò chơi, đọc hướng dẫn trên màn hình rồi bấm nút bắt đầu để trải nghiệm.
  4. Nhấn mục Trang chủ trên menu để quay lại phần đầu trang.

Lưu ý: Các file HTML bài tập phải được đặt cùng thư mục với file index.html.

🎯 MÔ TẢ TRÒ CHƠI

Các bài tập 28, 28a và 28b là những phiên bản trò chơi kiểm tra tốc độ phản xạ được xây dựng bằng HTML, CSS và JavaScript.

Người chơi cần nhấp chuột vào các mục tiêu xuất hiện trên màn hình để ghi điểm trong khoảng thời gian quy định. Tùy từng phiên bản, trò chơi có thể có cấp độ, mạng sống, mục tiêu nhiều màu sắc, bộ đếm thời gian hoặc bảng xếp hạng.

Mục đích là luyện khả năng quan sát, phản ứng nhanh và thực hành xây dựng hiệu ứng tương tác bằng JavaScript.
